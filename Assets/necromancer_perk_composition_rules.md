# 네크로맨서 퍼크 합성 규칙 & 밸런스 철학

## 0. 이 문서의 목적
이 문서는 **네크로맨서 로그라이크 게임**에서 퍼크(Perk)를 설계하고 합성할 때
밸런스를 *의도적으로 흔들되 붕괴하지 않게* 유지하기 위한 **명시적 규칙집**이다.

> 목표는 공정함이 아니라 **납득 가능한 불공정**이다.

---

## 1. 게임 철학 (고정 전제)
아래 항목은 설계 중 바뀌지 않는 **상위 철학**이다.

1. **퍼크 운이 나쁘면 클리어가 매우 어려워질 수 있다.**
   - 완전한 보정 장치는 두지 않는다.
   - 플레이 실력으로 어느 정도 커버는 가능하지만, 운이 나쁘면 고통스럽게 만든다.

2. **무지성 대깨 조합은 없다.**
   - 특정 퍼크 하나만 집으면 무조건 이기는 구조는 금지.
   - 대신 여러 퍼크가 *우연히* 맞물리면 강해질 수는 있다.

3. **사기 조합은 존재한다.**
   - 낮은 확률로 터지는 조합은 허용한다.
   - 로그라이크의 쾌감은 여기서 나온다.

4. **등급 높은 퍼크는 체감상 명확히 강하다.**
   - Rare / Epic / Legendary 퍼크를 먹으면 게임이 쉬워져야 한다.
   - 단, 항상 같은 방식으로 쉬워지지는 않는다.

5. **싱글플레이 로그라이크이므로 ‘사기칠 정도의 강함’은 허용한다.**
   - PvP 밸런스 기준은 고려하지 않는다.
   - 대신 시스템 붕괴(무한 루프, 즉사, 계산 폭주)는 금지.

---

## 2. 스탯별 적용 정책 (가장 중요한 규칙)

| 스탯 | 적용 정책 | 설명 |
|---|---|---|
| 공격력 | **Dynamic (즉시 반영)** | 퍼크 변경 시 기존 언데드에게도 즉시 적용 |
| 체력(HP) | **Snapshot (스폰/부활 시)** | 퍼크 변경으로 기존 언데드 HP는 변하지 않음 |
| 슬롯(최대 소환 수) | **Dynamic (즉시 반영)** | 퍼크 변경 즉시 슬롯 수 갱신 |

> 이 정책은 밸런스와 안정성을 동시에 만족시키기 위한 핵심 규칙이다.

---

## 3. 퍼크 합성의 기본 원칙

### 3.1 합성의 대원칙
1. **곱(Mul)은 적게, 덧(Add)은 많이 사용한다.**
2. 합성 순서는 항상 고정한다.
3. 퍼크 수가 늘어날수록 결과가 예측 가능해야 한다.

---

## 4. 최종 합성 공식 (표준형)

### 4.1 공격력 (Attack)

```
FinalAttack = (BaseAttack + ΣAddAttack) × ΠMulAttack
```

- `AddAttack` : 고정 증가, Common 퍼크의 주력 수단
- `MulAttack` : 배율 증가, Rare 이상 퍼크의 주력 수단
- 공격력은 **즉시 기존 언데드에게 반영**된다.

---

### 4.2 체력 (HP)

```
FinalMaxHP = (BaseHP + ΣAddHP) × ΠMulHP
```

- 규칙은 공격과 동일
- 차이점:
  - **기존 언데드에게는 절대 즉시 반영하지 않는다.**
  - 다음 소환 / 부활부터 적용된다.

#### 안전 규칙
- HP Mul은 매우 제한적으로 사용한다.
- 최종 Mul 결과는 반드시 클램프한다.

권장 범위:
```
0.3 ≤ TotalHPMul ≤ 3.0
```

---

### 4.3 슬롯 (최대 소환 수)

```
FinalSlot = BaseSlot + ΣSlotBonus
```

- 슬롯에는 **Mul을 사용하지 않는다.**
- 슬롯 증가는 항상 강력하므로 Rare 이상 퍼크에 배치하는 것을 권장.

---

## 5. 퍼크 타입 규격 (강제)

퍼크는 아래 타입 중 하나 이상을 가진다.

| 타입 | 설명 | 주 사용처 |
|---|---|---|
| FlatAdd | +n 형태의 고정 증가 | Common 퍼크 |
| Mul | ×m 형태의 배율 | Rare / Curse |
| SlotAdd | 슬롯 +n | Rare / Epic |

Override 계열은 극히 제한적으로만 사용한다.

---

## 6. Rare / Curse 퍼크 설계 가이드

### 6.1 Rare 예시

**Rare: 언데드 공격력 +50%, 체력 -30%**

- AttackMul ×= 1.5 (즉시 반영)
- HPMul ×= 0.7 (다음 소환부터)

→ 강력하지만 리스크가 명확하고 억울하지 않다.

---

### 6.2 Curse 예시

**Curse: 언데드 공격력 -20%, 슬롯 +1**

- AttackMul ×= 0.8
- SlotBonus += 1

→ 약화 + 확장이라는 로그라이크다운 선택지.

---

## 7. 폭주 방지 규칙 (필수)

합성 후 **최종 결과에만** 클램프를 적용한다.

- AttackMul: `0.1 ~ 10`
- HPMul: `0.3 ~ 3.0`
- FinalMaxHP ≥ 1
- FinalAttack ≥ 0 (또는 1, 설계 선택)

> 퍼크 개별에 클램프를 걸지 말고, 항상 최종 결과에만 적용한다.

---

## 8. 밸런스 검증 기준 (튜닝 시 사용)

최소한 아래 지표는 수치로 본다.

1. **언데드 1마리 평균 생존 시간**
2. **언데드 1마리 평균 처치 기여 수**
3. **슬롯 +1이 전투 난이도에 미치는 체감 변화**

Rare 퍼크를 먹어도
- 전투가 즉시 무너지는지
- 또는 ‘아, 쎄다’ 수준에서 멈추는지

을 여기서 판단한다.

---

## 9. 최종 요약

- 공격: 즉시 반영, 곱 중심
- 체력: 스냅샷 적용, Add 중심
- 슬롯: +만 사용, 즉시 반영
- 사기 조합은 허용하되 시스템 붕괴는 금지

이 규칙을 벗어나는 퍼크는 **의도적으로 깨는 특수 콘텐츠**로만 허용한다.
